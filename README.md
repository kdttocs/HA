# Home Assistant app repository

Home Assistant apps (add-ons) by kdttocs. Each app lives in its own folder, with its own guide, security notes and
everything else it needs.

**Add this repository to Home Assistant:** **Settings > Apps > App store > ⋮ > Repositories**, paste
`https://github.com/kdttocs/HA`, tap **Add**. The apps then appear in the App store.

| App | What it does |
| --- | --- |
| [Hark Home Assistant Gateway](hark_gateway) | Lets Hark help with your home network: looks freely, changes only with your yes. |
| [Internet Receipt Printer](internet_receipt_printer) | Prints messages from your own public web form on a receipt printer at home. |
